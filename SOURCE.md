# Source and adaptation

MIT sources, copied or adapted into Terrace; no sibling was edited.

- Base `fc0e1041efa55771142bbb57c4ab4743147e264d`: generated committed foundation, then composed its runtime. `composition.lock.json` records copied foundation files. CLI uses package mode; `package.json` records its exact `@runeditrun/rer` devDependency. Operator auth, theme/frame, deployment, portability and import-kit retain their shared implementations.
- `run-gasket` `3f87ba0fdba9955f2b7d018d10afafcd50afa919`, `src/gasket/work.ts`: bounded photograph custody, content hashes and version-guarded inspection writes in `src/terrace/work.ts`.
- `run-glove` `778474d80bf5f440b42fb8f3364a191908d0e4b9`, `src/glove/commands/dispatch.ts`: reviewed trade assignment and version-bound handoff, adapted to immutable approval snapshots in `src/terrace/work.ts`.
- `run-locket` `82478229f356d017bda62b4944b584138ef9671c`, `src/locket/obligations.ts`: proposed/confirmed lease terms with previous terms retained in `src/terrace/tenancies.ts`.
- `run-nectar` `c76a60ccffa39cc1a207b52c152bda16d6d7b1df`, `src/nectar/receivables.ts`: integer-cent charge/receipt arithmetic and transactional balance guards in `src/terrace/ledger.ts`.
- `run-coaster`, `run-beam` and `run-pier` main package-mode command adapters informed package setup, local portability and the real-D1 HTTP test harness.

Terrace tenancy CSV v1 is a documented native shape, not a claimed PropertyMe or Buildium export adapter. Automatic rent generation and recurring inspection schedules are outside this first cycle.

## Demo runtime refresh

The application’s vendored Base modules (including demo, operator-auth,
owner-claim, mail and import-kit’s d1-transport) are copied together from
`rer-v0.2.30` (`d434ea67989fe10b6ddff01daba8bb350975e54a`). Three mail and
dependencies files keep Terrace's linear-parsing CodeQL fixes on top of those
bytes and stay out of the copy record until Base takes the fixes.
`base-copies.json` records their exact bytes through Base’s `record-base` /
`refresh-base` tooling. The composition lock retains the original assembly
and applied migrations; refreshed runtime copies are owned by the copy inventory.
The additive owner-signin migration retains the new Base schema separately.
The repo uses package mode and has no edition recipe or sources.lock.json.

Demo inspection photographs reuse the existing Terrace sink and tap artwork,
converted to JPEG for the inspection store. The first two sample properties
come from the documented tenancy CSV; all sample dates follow demo startup.
