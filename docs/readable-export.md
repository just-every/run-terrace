# Readable operating export

Download the readable ZIP from Data & access. Keep it private: original documents retain their exact contents, including restricted files. Use the separate private backup to restore into an empty installation.

The ZIP includes Tenancies, Charges, Receipts, Inspections and Maintenance when those records exist. Other nonempty collections are grouped into named product sheets, such as Accounts and payments, Leasing and households, and Documents and conversations. These sheets list each record's fields with a readable reference so related records can be followed without internal identifiers. Collections.csv lists the included collections and record counts.

Dates use month names, times are labelled UTC, money is in decimal currency units, and saved structured details are expanded into labelled text. Original IDs, technical policy references and structured-data notation are not needed to read these display copies. Export references are stable within the downloaded ZIP; they are not permanent application identifiers.

Original files retain their exact bytes. Published attachments stored in chunks are assembled into complete originals and checked before export. The file inventory gives a readable path, linked record, size in KB or MB and SHA-256 checksum. Restricted document metadata remains redacted. Original files may contain identifiers or technical notation supplied in their own contents; rewriting those bytes would destroy original evidence.

Empty collections and internal installation machinery, including sign-in state, concurrency guards, import staging and erasure suppression records, are omitted from the display sheets. They remain in the private backup wherever required for restore and custody. User operating events, approvals, historical versions, provider observations, financial records, source references and original files are included. Reconnection instructions explain which identities, permissions and providers must be configured again. Restored evidence authorizes no send or payment.
